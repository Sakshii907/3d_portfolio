# 3D Portfolio Website

A  3d responsive personal portfolio website showcasing my technical skills, projects, certifications, and professional journey as a Computer Science Engineering student specializing in Artificial Intelligence.

## 🚀 Features

* **About Me** — Introduction, education, and career interests.
* **Skills** — Technical skills, programming languages, and development tools.
* **Projects** — Highlights of my projects in software development, machine learning, and AI.
* **Certifications** — Relevant certifications and achievements.
* **Contact** — Links to connect with me professionally.
* **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
